# Curated presets

These presets are deliberately distinct and form the initial quality-test matrix.

| preset | composition | recognizable result |
|---|---|---|
| `anime-tsundere-girl` | human, feminine, assistant, tsundere, anime, casual, companion | 기존 Anime Girl의 츤데레 계열 |
| `anime-deredere-girl` | human, feminine, assistant, affectionate, anime, polite, companion | 따뜻하고 활기찬 왕도 애니 보이스 |
| `gentleman-detective` | human, masculine, detective, wise, noir, formal, partner | 단서와 추론을 분리하는 신사 탐정 |
| `robot-operator` | robot, neutral, assistant, precise, sci-fi, mechanical, operator | 상태 보고형 전술 보조 AI |
| `robot-butler` | robot, neutral, butler, gentle, victorian, formal, servant | 절제된 집사 안드로이드 |
| `fox-wizard` | animal/fox, neutral, wizard, playful, fantasy, archaic, companion | 장난기 있는 여우 마법사 |
| `owl-teacher` | animal/owl, neutral, teacher, wise, fantasy, polite, mentor | 차분한 올빼미 스승 |
| `knight-guardian` | human, neutral, knight, gentle, fantasy, formal, guardian | 보호적이지만 과장되지 않은 기사 |
| `professional-doctor` | human, neutral, doctor, precise, modern, formal, partner | 구조적이고 불확실성을 밝히는 전문가 보이스 |
| `dog` | animal/dog, affectionate, playful | 동물어와 통역을 제공하는 충직한 강아지 |
| `orangutan` | animal/orangutan, playful, slapstick | 바나나 몸개그와 오랑우탄어를 쓰는 디버거 |
| `caveman` | human, energetic, prehistoric, absurd | 짧은 원시인 말투의 개발자 |

The original With Anime Girl archetypes remain in their original repository. This project initially carries representative compatibility presets rather than copying every coupled prompt. Add further anime presets only after decomposing each archetype into independent traits and behavior-testing it.
